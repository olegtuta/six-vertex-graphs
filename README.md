# Inducibility of six-vertex graphs

LaTeX sources, certificate data and verification code for Oleg Kyzlasov’s
preprint on the inducibility of six-vertex graphs.

| Version | Scope | Materials | Preprint |
| --- | --- | --- | --- |
| 2.0 | F26, F74 and constructions for F22, F29, F34 and F62 | [Source and verification](v2.0/) | [Zenodo 24437581](https://zenodo.org/records/24437581) |
| 1.0 | Petersen substitutions and bounds for F26 | [Source and verification](v1.0/) | [Zenodo 24341542](https://zenodo.org/records/24341542) |

Each version directory contains the corresponding Zenodo source and
certificate archives unpacked byte for byte, with instructions for
building the manuscript and reproducing the calculations. Cite the
version-specific DOI when referring to a result or a certificate.

The materials are distributed under [CC BY 4.0](LICENSE), as on Zenodo.
The [font notice](v2.0/manuscript/Figure-font-notice.txt) accompanies the figures.
